# Baozi Store - API REST

Projeto desenvolvido para a disciplina de Desenvolvimento Web Back-End do curso de Análise e Desenvolvimento de Sistemas - UNINTER.

## Tecnologias

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## Execução

A aplicação utiliza o banco de dados MySQL
baozi_store e executa na porta 8080.
